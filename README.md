# Bromid

Небольшой настольный браузер на Chromium (Electron): вкладки, адресная строка, навигация, перезагрузка и горячие клавиши.

## Запуск

Нужен [Node.js LTS](https://nodejs.org/). В корне проекта выполните:

```powershell
npm install
npm start
```

## Горячие клавиши

- `Ctrl+L` — адресная строка
- `Ctrl+T` — новая вкладка
- `Ctrl+W` — закрыть вкладку
- `Alt+←` / `Alt+→` — назад / вперёд
- `Ctrl+R` — перезагрузить страницу
